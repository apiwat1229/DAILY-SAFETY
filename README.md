# Daily Safety — Y.T. Rubber

เว็บแอปบันทึกแบบตรวจความปลอดภัยประจำวันจากไฟล์ `Daily_Safety_Leader_Checklist.xlsx` ใช้ React, Vite, Tailwind CSS และคอมโพเนนต์ shadcn/ui พร้อม Express API และ SQLite สำหรับเก็บข้อมูลกลางกับหลักฐานภาพ

## เริ่มใช้งานในเครื่อง

ต้องติดตั้ง Node.js 24 ขึ้นไปและ pnpm ก่อน

```powershell
pnpm install
pnpm dev
```

เปิดเว็บที่ `http://localhost:5173`

บัญชีสำหรับเปิดดูตัวอย่าง:

| บทบาท | ชื่อผู้ใช้ | รหัสผ่าน |
| --- | --- | --- |
| Admin | `admin` | `Admin@123` |
| หัวหน้างาน | `leader` | `Leader@123` |

Admin ดูภาพรวมและรายงาน ค้นหาตามวันที่ พื้นที่ กะ ผลตรวจ สถานะ และหัวข้อตรวจ จัดการงาน NG และเพิ่มบัญชีผู้ใช้ได้ หัวหน้างานกรอกแบบตรวจและดูประวัติของตนเอง

## การเก็บข้อมูล

- SQLite: `data/daily-safety.sqlite`
- รูปแนบ: `data/uploads/`
- ข้อมูล SQLite และรูปไม่ถูกใส่ใน Git
- รูปต่อไฟล์ไม่เกิน 8 MB แนบได้สูงสุด 20 รูปต่อแบบตรวจ และขนาดรวมไม่เกิน 60 MB
- รายงานส่งออกเป็น CSV ที่เปิดด้วย Excel ได้

หัวข้อ NG ต้องมีรายละเอียด ผู้รับผิดชอบ และรูปก่อนแก้ไข การปิดงานต้องแนบรูปหลังแก้ไข กำหนดเสร็จเป็นช่องไม่บังคับ แต่ใช้คำนวณงานเกินกำหนด

## ใช้งานบนเซิร์ฟเวอร์จริง

แอปมี Docker image สำหรับรันหลัง Nginx Proxy Manager และเก็บ SQLite กับรูปแนบไว้ใน Docker volume:

```sh
cp .env.example .env
# เปลี่ยน SESSION_SECRET, ADMIN_PASSWORD และ LEADER_PASSWORD เป็นค่าที่คาดเดายาก
docker compose up -d --build
```

เพิ่ม Proxy Host ใน Nginx Proxy Manager โดยตั้ง Forward Hostname/IP เป็น `172.20.0.4`, Forward Port เป็น `4000` และเปิด HTTPS ด้วยใบรับรองของโดเมน Compose จอง IP นี้ให้แอปบน network `nginx-proxy-manager_default` แอปไม่มีการ publish port ออกสู่ host โดยตรง หาก network ของเซิร์ฟเวอร์ใช้ subnet อื่น ให้ปรับ IP ให้ตรงกันทั้ง Compose และ NPM

ข้อมูล SQLite และรูปอยู่ใน volume `daily-safety-data` สำรอง volume นี้เป็นประจำ และเก็บไฟล์ `.env` ให้เข้าถึงได้เฉพาะผู้ดูแลระบบ เมื่อตั้งรหัสผ่านใน `.env` หลังสร้างฐานข้อมูลแล้ว แอปจะอัปเดตรหัสบัญชีเริ่มต้น `admin` และ `leader` ตอนเริ่มเซิร์ฟเวอร์ บัญชีที่สร้างเพิ่มจากหน้า Admin ยังคงแยกต่างหาก

## ขอบเขตรุ่นนี้

- รายการตรวจ 13 ข้ออิงจากแบบฟอร์ม Excel
- ผลตรวจ `OK`, `NG`, `N/A`; `N/A` นับว่าได้ตรวจแล้ว
- พื้นที่และกะเป็นข้อความที่กรอกได้ เพื่อไม่จำกัดรายการพื้นที่ของโรงงาน
- รองรับบัญชี Admin และหัวหน้างาน พร้อมแยกสิทธิ์ดูข้อมูล
- ข้อมูลเดิมจาก Excel ยังไม่ได้ import เข้าฐานข้อมูล
